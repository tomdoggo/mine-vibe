# 深渊老虎机（abyss-slots）

3D 像素暗黑风 3×3 老虎机 Demo。10 枚金币开局，目标是 100 转之内赢到尽可能多的金币。

- 每转 10 次深渊加深一层，下注上限翻倍（1 层上限 10，2 层 20，3 层 40……）
- 开局和每转 5 次，从随机 2 个玩偶里挑 1 个摆在币盘两侧（左右各 5 个），也可以跳过改拿 5 金币
- 点玩偶可以半价（2 金币）卖掉；点盘面上的符号可以看算上玩偶之后的实际赔率
- 技术栈：Vite + TypeScript + three.js（界面是 DOM 叠在 WebGL 画布上），竖屏优先
- 图案、金币贴图、音效全部在运行时生成，没有任何美术 / 音频资源文件

## 运行

```bash
npm install
npm run dev     # http://localhost:5178 ，同一 Wi-Fi 下手机可用终端打印的 Network 地址打开
npm run build   # 类型检查 + 打包
npm run sim     # 数值模拟：返还率、中奖率、各种下注 / 拿玩偶策略打完 100 转的结果分布
npm run artifact  # 打成单文件 artifact/abyss-slots.html，用来发布到 claude.ai
```

网址加 `?seed=123` 可以复现同一局。开发模式下控制台输入 `__slot.win(500)` 可以直接看金币雨，`__slot.give('raven')` 白拿一个玩偶。

操作：点盘面上的符号看实际赔率，点玩偶看效果 / 出售。

## 规则

- 9 个格子各自独立按权重抽符号
- 横、竖、斜共 8 条线，任意一条三连即中奖，奖金 = 下注 × 赔率，多条线叠加
- 赔率达到 15 倍算大奖：金币雨 + 震屏
- 金币输光或 100 转用完即结算

## 玩偶

10 个玩偶各限一个，按拿到的顺序摆上台阶（左右交替），卖掉后面的往前补位。定义和数值都在 `src/game/config.ts`，结算逻辑在 `src/game/slot.ts`。所有数值向下取整。

| 玩偶 | 效果 | 单独带它时的返还率增量 |
| --- | --- | --- |
| 烛灵 | 残烛三连的赔率 ×1.5 | +19% |
| 幽灵 | 没中奖时 25% 概率退还下注 | +14% |
| 吞金鼠 | 每转结束，获得持有金币的 1%（至少 1） | 看身家，不看下注 |
| 渡鸦 | 中了匕首三连，立即免费再转一次（可连锁） | +9% |
| 魔眼蝠 | 魔眼三连的赔率 ×3 | +20% |
| 黑猫 | 连续 3 转没中后，下一次中奖奖金 ×2 | +19% |
| 骷髅兵 | 骷髅和冥币出现得更频繁 | +13% |
| 双头犬 | 同时中 2 条线以上，奖金 ×2 | +30% |
| 猫头鹰 | 奖金达到下注 10 倍时，再 ×2 | +13% |
| 宝箱怪 | 下注不低于上限的一半时，奖金 ×1.3 | +27% |

基础返还率约 89%（不带玩偶是亏的），凑齐两三个玩偶才开始赚钱，效果之间相乘叠加。数字来自 `npm run sim`。

## 画面是怎么做的

- 机器和场景只渲染 400 行像素，再用最近邻放大到屏幕（`scene.ts` 的 `PIXEL_ROWS`）
- 金币例外：放大之后按屏幕原生分辨率单独再画一遍，用低清那一遍的深度图做遮挡，所以金币是高清立体的，其余是像素块
- 符号先用矢量路径画，再缩到 32×32 并压色（`symbols.ts` 的 `pixelate`）；玩偶是手点的 12×12 像素画（`dollArt.ts`）
- 镜头会避开顶栏和底部面板（`Stage.setInsets`），机器始终完整落在两者之间

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/game/config.ts` | 所有可调数值：初始金币、转数、符号权重与赔率 |
| `src/game/slot.ts` | 纯逻辑：抽盘面、判奖、对局状态（不依赖渲染，`sim` 直接复用） |
| `src/render/scene.ts` | 机器模型、灯光、相机、泛光后期 |
| `src/render/reels.ts` | 3 个滚筒的旋转动画与中奖线高亮 |
| `src/render/coins.ts` | 金币喷射、弹跳、堆积（InstancedMesh + 沙堆模型，不用物理引擎） |
| `src/render/symbols.ts` | 用 canvas 现画的符号 / 金币 / 招牌贴图 |
| `src/render/dolls.ts`、`dollArt.ts` | 玩偶台阶、玩偶像素画 |
| `src/audio.ts` | WebAudio 合成音效 |
| `scripts/sim.ts` | 数值模拟脚本 |
